# SQL01: Big Data и SQL (комплект слушателя)

Учебный стенд, данные, презентации и практические задания курса «Big Data и SQL: инженерия данных, ETL и оптимизация запросов» (PostgreSQL 17.12, ClickHouse 26.8.36.3, Python).

- **Прямая ссылка на архив (в 1 клик):** [SQL01_learner.zip](https://github.com/ziablitsev/sql01-kit/releases/latest/download/SQL01_learner.zip)
- **Страница релиза:** [Releases / v1.0.0](https://github.com/ziablitsev/sql01-kit/releases/tag/v1.0.0)

## Быстрый старт после скачивания

1. **Полностью распакуйте** архив `SQL01_learner.zip` в отдельную папку (не открывайте файлы прямо из окна архиватора):
   - на **Windows:** например, в `C:\SQL01` или `%USERPROFILE%\SQL01`;
   - на **Ubuntu Linux:** например, в `~/SQL01`.
2. Откройте в браузере файл **`00_ОТКРЫТЬ.html`** в корне распакованной папки.
3. Для развёртывания баз данных к Занятию 02 откройте пошаговую инструкцию вашей ОС:
   - **Windows 10 / 11:** `stand/УСТАНОВКА_WINDOWS.html`
   - **Ubuntu Linux 22.04 / 24.04 (и WSL 2):** `stand/УСТАНОВКА_UBUNTU.html`
   - **PostgreSQL без Docker (резервный вариант):** `stand/POSTGRESQL_БЕЗ_DOCKER.md`

На первом занятии локальные базы не требуются: архитектурная практика выполняется по материалам `КУРС/01/03_Практика.md`.
